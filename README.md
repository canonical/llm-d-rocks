# llm-d-rocks

Canonical [rocks](https://documentation.ubuntu.com/rockcraft/) (OCI images built
with Rockcraft) for components of [llm-d](https://github.com/llm-d).

| Rock | Description |
| --- | --- |
| [`llm-d-inference-scheduler`](llm-d-inference-scheduler/) | Inference scheduler ("Endpoint Picker", `epp`) |
| [`llm-d-routing-sidecar`](llm-d-routing-sidecar/) | Routing sidecar (`pd-sidecar`) |

Each directory has its own `rockcraft.yaml`, tests and README.
